# Advanced Weather App

## OASIS INFOBYTE Internship

**Internship Track:** Python Programming  
**Task:** Task 4 – Basic Weather App  
**Project Level:** Advanced  
**Project Type:** Python GUI Application

## Overview

The Advanced Weather App is a Python-based GUI application developed as part of the OASIS INFOBYTE Python Programming Internship.

The application allows users to search for a city and view real-time weather information using the OpenWeatherMap API.

It also provides weather icons, forecast information, temperature unit conversion, input validation, and error handling.

## Features

- Real-time weather information
- City-based weather search
- Temperature in Celsius and Fahrenheit
- Weather condition
- Humidity
- Wind speed
- Atmospheric pressure
- Weather icons from OpenWeatherMap
- Next 6-hour forecast information
- 5-day forecast
- Celsius/Fahrenheit toggle
- Empty-input validation
- Invalid-city error handling
- API error handling
- Internet connection error handling
- Responsive maximized GUI
- Enter key support for searching

## Technologies Used

- Python
- Tkinter
- Requests
- Pillow
- Python-dotenv
- OpenWeatherMap API
